# Certificates Directory

Drop your certificate files (PDFs, PNGs, JPGs) into this folder.

To link each certificate in your portfolio:
1. Place your certificate file here (e.g. `cert-aws.pdf`, `cert-web-dev.png`).
2. Update the `href` attribute of the corresponding `.cert-link` inside `index.html` (e.g., `href="assets/certificates/cert-aws.pdf"`).
